# Support

## Archival and migration

This repository is being prepared for archival. Once archived, it will be read-only
and new issues and pull requests cannot be submitted here.

Please migrate to the
[Microsoft OpenTelemetry Distro for Node.js](https://github.com/microsoft/opentelemetry-distro-javascript)
(`@microsoft/opentelemetry`). Start with its
[getting started guide](https://github.com/microsoft/opentelemetry-distro-javascript#getting-started).
For Azure Monitor and Application Insights setup, see the
[Microsoft OpenTelemetry setup guide](https://learn.microsoft.com/en-us/azure/azure-monitor/app/opentelemetry-enable?tabs=nodejs).

For bugs and feature requests related to the distro, search its
[existing issues](https://github.com/microsoft/opentelemetry-distro-javascript/issues)
before opening a new issue there.

## Microsoft Support Policy  

Support resources for the recommended replacement are listed above. Archival of
this repository does not change the support policy of that project.
